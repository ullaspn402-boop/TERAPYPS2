# SPEECHCARE AI

Intelligent speech-language therapy and clinical supervision platform connecting acoustic speech analysis, adaptive progression, and clinical oversight.

## Features

- **Intelligent Speech Therapy**: Assistive tools for voice, speech pattern recognition, and sound-based speech analysis.
- **Adaptive Progression**: Tracks patients' milestones and dynamically recommends therapy exercises.
- **Clinical Supervision**: Connects supervisors and students/therapists for training and reviewing clinical reports.
- **Beautiful Dashboard**: Sleek and modern user interface designed with React and Tailwind CSS.

## Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
